# 01 · SRCNN ×3

[Lornatang/SRCNN-PyTorch](https://github.com/Lornatang/SRCNN-PyTorch) 를 우리 위성 데이터로 학습.
신경망 정의(`model.py`)와 이미지 처리(`imgproc.py`)는 업스트림 사본을 **한 글자도 고치지 않고**
`lib/srcnn_arch.py` · `lib/srcnn_imgproc.py` 로 가져왔다.

2014년 논문. **이 분야 최초의 CNN** 이고 여기 있는 여섯 모델 중 가장 오래됐다.
번호는 마지막이지만 계보상으로는 맨 앞이다.

| | |
|---|---|
| 구조 | conv 9×9 → 5×5 → 5×5, 채널 1-64-32-1 |
| 손실 | **MSE** (업스트림 그대로) |
| 입력 | 실제 Sentinel-2 LR (10 m) 을 **bicubic 으로 3배 키운 것**의 Y 채널 |
| 목표 | IKONOS HR (3.3333 m) 의 Y 채널 |
| 학습 | IKONOS 804쌍, 100 epoch, batch 16, LR 크롭 48, Adam 2e-4 (50·75·90% 지점 절반) |
| 가중치 | `checkpoints/srcnn_x3.pth` (57.3K) |
| 노트북 | [`../../notebooks/01_srcnn_x3.ipynb`](../../notebooks/01_srcnn_x3.ipynb) |

추가 설치가 필요 없다. Colab 기본 패키지로 돈다.

## 규약이 둘 다르다

**1. 모델 안에 업샘플이 없다.** conv 3장이 전부라 크기를 못 바꾼다. 입력을 미리
bicubic 으로 3배 키워 HR 과 같은 크기로 넣는다. 여기서 ×3 은 "모델이 3배 키운다"가
아니라 "3배로 키워둔 흐린 영상을 모델이 다듬는다"는 뜻이다. 그래서 bicubic 이
baseline 이 아니라 **입력 그 자체**다.

**2. Y(밝기) 채널 하나만 본다** (`nn.Conv2d(1, 64, ...)`). 색(Cb, Cr)은 bicubic
확대본을 그대로 붙인다. SRCNN 은 색을 바꾸지 못하고 선명도만 손본다.

`lib/srcnn_models.py` 의 `srcnn_upscale()` 이 이 전처리·후처리를 감싼다
(업스트림 `inference.py` 와 같은 순서).

## 데이터셋만 갈아끼웠다

업스트림 `dataset.py` 는 **HR 을 축소해 LR 을 만든다**. 우리는 그러지 않는다 —
데이터셋에 들어 있는 실제 Sentinel-2 LR 을 읽어서 bicubic 으로 키워 넣는다.
모델이 보는 입력은 언제나 실제 관측 영상이어야 한다.
`SRCNN/sr_dataset_srcnn.py` 가 그 어댑터이고, 모델·손실은 손대지 않았다.

bicubic 확대와 YCbCr 변환은 업스트림 `imgproc.py` 함수를 그대로 쓴다.
학습 때와 같은 함수여야 추론 결과가 맞는다.

## 최적화기는 업스트림 값을 못 썼다

업스트림은 **SGD lr 1e-4** (reconstruction 층만 0.1배)를 쓰는데, 이건 `epochs = 58000`
을 전제한 값이다. 100 epoch 로는 학습이 시작도 안 된다:

| 3 epoch 후 검증 PSNR | |
|---|---|
| Bicubic (기준) | 15.49 |
| SGD 1e-4 (업스트림) | **8.89** |
| Adam 2e-4 | **15.75** |

SRCNN 은 reconstruction 층을 σ=0.001 로 초기화해 **출력이 0 에서 시작**하고,
잔차가 아니라 전체 매핑을 배운다. SGD 1e-4 로는 0 에서 거의 못 벗어난다.

모델과 손실(MSE)은 업스트림 그대로 두고 **최적화기만** 다른 모델들과 같은 조건
(Adam 2e-4 + MultiStepLR)으로 맞췄다. 그래야 표의 비교가 최적화기가 아니라
구조의 차이를 보여준다.

## 학습 경과

| epoch | MSE | 검증 PSNR(Y) | lr |
|---|---|---|---|
| 1 | 0.034952 | 15.37 | 2e-4 |
| 29 | 0.009288 | **15.91** | 2e-4 |
| 50 | 0.009371 | 15.88 | 1e-4 |
| 100 | **0.009105** | 15.73 | 2.5e-5 |

학습 중 PSNR 은 IKONOS 검증 12씬의 **Y 채널** 값이라 아래 표(RGB, 검증 10패치)와
기준이 다르다. epoch 29 가 가장 높지만, 공유 검증 10패치로 다시 재면 마지막이 낫다:

| 체크포인트 | PSNR | SSIM |
|---|---|---|
| epoch 29 (best) | 18.30 | 0.5037 |
| **epoch 100 (latest)** | **18.40** | **0.5206** |

그래서 `checkpoints/srcnn_x3.pth` 는 epoch 100 이다.

MSE 는 epoch 1 이후 거의 평평하다. conv 3장으로 배울 수 있는 것을 일찍 다 배운다.

## 일곱 모델 비교 (검증 10패치 / 인천)

| 모델 | PSNR | SSIM | 인천 선명도 | 파라미터 |
|---|---|---|---|---|
| Bicubic | 18.15 | 0.4805 | 9.83 | — |
| **SRCNN** | **18.40** | **0.5206** | 13.13 | **57.3K** |
| EDSR | 18.97 | 0.5462 | 14.60 | 1.55M |
| SRGAN | 18.30 | 0.5187 | 22.03 | 0.77M |
| ESRGAN | 17.87 | 0.4929 | **30.26** | 5.91M |
| SwinIR | 19.04 | 0.5483 | 13.88 | 11.94M |
| HAT | 19.06 | 0.5505 | 14.07 | 20.81M |

**57.3K 로 SRGAN(771K) 을 PSNR 에서 이긴다.** 2014년 모델이 2017년 GAN 모델보다
화소 정확도가 높다 — GAN 이 정확도를 버리고 질감을 택했기 때문이지 SRCNN 이
더 좋아서가 아니다. 선명도는 13.13 대 22.03 으로 SRGAN 이 한참 앞선다.

**SRCNN → HAT 은 파라미터 363배에 PSNR 0.66 dB.** bicubic 위로 올린 이득으로 보면
0.25 dB → 0.91 dB, 3.6배다. 363배를 들여 3.6배를 얻는다. 학습(합성 LR)과
검증(실제 Sentinel-2)의 도메인 차이가 병목이라는 진단과 일치한다.

`statistics/train_results.csv` 에 epoch 별 MSE·PSNR·학습률 100행.

## g_LR 변형 10종으로 2 epoch 이어 학습 (2026-09-04)

같은 HR 에 열화 세기가 다른 g_LR 을 10벌 만든 학습셋(486타일 × 10 = 4,860장)으로
배포 체크포인트에서 2 epoch 을 더 돌렸다. 검증은 그대로 공유 10패치다.

| | PSNR | SSIM |
|---|---|---|
| 이전 | 18.40 | 0.5206 |
| **현재 (배포본)** | **18.40** | **0.5218** |

**변화가 작다.** 이미 수렴한 모델이라 2 epoch 으로는 크게 안 움직인다. PSNR 은 사실상 제자리이고 SSIM 만 소폭 올랐다.

일곱 모델 중 SRGAN·ESRGAN 은 교체하지 않았다. SRGAN 은 이어 학습에서 판별자가
붕괴했고(`D(x)=D(G(z))=1.0`), ESRGAN 은 PSNR 은 올랐으나 SSIM 이 내려가 방향이 엇갈렸다.
