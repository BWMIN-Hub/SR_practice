# 05 · ESRGAN ×3

[xinntao/ESRGAN](https://github.com/xinntao/ESRGAN) 구성을 우리 위성 데이터로 학습.

**업스트림 저장소에는 학습 코드가 없다**(`test.py` 와 `net_interp.py` 뿐).
그래서 논문 구성을 따라 `ESRGAN/train_esrgan.py` 를 새로 작성했다.

| | SRGAN | ESRGAN |
|---|---|---|
| 생성자 | SRResNet | **RRDB** (BatchNorm 없음) |
| 화소 손실 | MSE (가중치 1.0) | **L1** |
| 지각 손실 | VGG16, 활성화 **이후** (0.006) | **VGG19 conv5_4, 활성화 이전** |
| 적대적 손실 | 절대 판정 (0.001) | **RaGAN** 상대 판정 |

ESRGAN 쪽 가중치는 아래 "손실 가중치를 재조정했다" 를 보라.

| | |
|---|---|
| 입력 | 데이터셋이 제공하는 Sentinel-2 LR (10 m) |
| 목표 | IKONOS HR (3.3333 m), LR × 3 |
| 학습 | IKONOS 804쌍, batch 16, crop 96, RRDB 8블록. 100 epoch(논문 가중치) + 10 epoch(재조정) |
| 가중치 | `checkpoints/esrgan_g_x3.pth` (epoch 58 에서 재조정 10 epoch) |
| 노트북 | [`../../notebooks/05_esrgan_x3.ipynb`](../../notebooks/05_esrgan_x3.ipynb) |

## ×3 을 위해 고친 곳

업스트림 RRDBNet 은 `F.interpolate(scale_factor=2)` 를 두 번 해서 ×4 고정이다.
배율을 인자로 받아 ×3 이면 한 번만 하도록 바꿨다. 계층 이름은 그대로라
×4 사전학습 체크포인트도 그대로 실린다.

## 판별자가 무너지지 않는다

SRGAN 은 epoch 37 에서 `D(x)`·`D(G(z))` 가 함께 1 로 붙어 적대적 신호가 사라졌다.
ESRGAN 은 110 epoch 내내 유지된다.

| | `D(x)` | `D(G(z))` |
|---|---|---|
| 범위 | 0.409 ~ 0.974 | 0.002 ~ 0.252 |

RaGAN 이 "진짜인가" 대신 **"평균적인 가짜보다 더 진짜 같은가"** 를 묻기 때문이다.
판별자가 한쪽으로 쏠려도 상대 비교라 기울기가 남는다.

## 손실 가중치를 재조정했다

논문 기본값으로 100 epoch 을 돌린 뒤 배치 로그를 열어 보니, **Loss_G 의 96.9% 가
지각 손실 하나였다.** 화소 손실은 0.06% 로 사실상 없는 것과 같았다.

| 항 | 논문 기본 | 비중 | → 재조정 | 비중 |
|---|---|---|---|---|
| pixel (L1) | ×0.01 | 0.06% | **×1** | **32.7%** |
| perceptual (VGG19) | ×1 | 96.87% | **×0.1** | 64.5% |
| gan (RaGAN) | ×0.005 | 3.07% | **×0.0005** | 2.8% |

원래 값만 보면 gan 이 10.0 으로 제일 크고 pixel 이 0.096 으로 제일 작다.
**가중치를 곱하면 순위가 정반대로 뒤집힌다** — 가중치를 반영하지 않은 손실 곡선을
보고 "GAN 이 학습을 주도한다" 고 읽으면 완전히 틀린다.

gan 은 가중치를 10배 줄였는데 비중이 3.07% → 2.8% 로 거의 안 줄었다. 판별자가
생성자를 더 쉽게 이기게 되면서 gan 원래 값이 10.0 → 13.5 로 커져 상쇄했기 때문이다.

## 성능 (검증 10패치)

| | PSNR | SSIM |
|---|---|---|
| Bicubic | **18.15** | 0.4805 |
| SRGAN | 18.30 | 0.5187 |
| ESRGAN (논문 가중치, 100 epoch) | 16.55 | 0.4208 |
| **ESRGAN (재조정, +10 epoch)** | **17.87** | **0.4929** |

**10 epoch 만에 PSNR +1.32, SSIM +0.072.** 화소 손실이 실제로 일을 시작한 결과다.
SSIM 은 처음으로 bicubic 을 넘었다.

PSNR 은 아직 bicubic 아래인데, 그것까지는 설계 결과다. 원논문은 PSNR 지향 모델을
먼저 학습한 뒤 GAN 으로 미세조정하는데 여기서는 처음부터 GAN 으로 돌렸다.

**주의: 판별자가 일방적으로 이기는 중이다.** 재조정 구간에서 `D(x)` 가 0.84 → 0.97 로
오르고 `Loss_D` 가 0.0000 을 자주 찍는다. 이 설정으로 더 길게 돌리면 기울기가 말라
GAN 항이 죽는다. `--lr_d` 를 낮추거나 gan 가중치를 더 줄여야 한다.

`statistics/train_results.csv` 에 epoch 별 지표 110행 (`phase` 열이 1 이면 논문
가중치, 2 면 재조정), `ESRGAN/statistics/esrgan_x3{,_w1}_batch.csv` 에 배치별 기록.
